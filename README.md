# Cybersecurity Tools

A collection of small cybersecurity utilities developed while studying cybersecurity fundamentals and Python programming.

The projects in this repository focus on implementing basic security concepts such as hash analysis, dictionary-based password recovery, web content discovery, and network reconnaissance.

These tools were developed primarily for educational purposes and authorized security testing.

## Purpose

These projects were created as part of my early cybersecurity training and are intended to demonstrate practical implementation of fundamental security concepts.

They are deliberately lightweight and educational rather than production-grade security tools.

## Disclaimer

These tools are intended for educational purposes and authorized security testing only.

Do not use them against systems, networks, or applications without appropriate authorization.
